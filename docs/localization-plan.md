# 中文／English实现进度与后续方案

**当前进度：管理器2.0.0、MPfix与性能跟踪器已接入中文／English切换。** Shared已提供共享显示语言、文本目录和规范化元数据；组件已分离版本，当前版本与适配声明见[版本契约](component-versions.md)。外部配置可按[显示接入规范 v1](manager-ui-contract.md)选择接入；存档编辑器与未接入外部模组的内容仍保留原文。

## 目标与选择入口

管理器标题栏提供`简体中文`、`English`切换，自身配置提供`UI/Language`，默认中文、立即生效并保存在本机。管理器使用自身内嵌文本目录，MPfix与性能跟踪器使用各自内嵌完整原文映射；通过Shared统一语言，不自动跟随游戏语言。配置原键、页面ID和业务状态不翻译；实验性布尔标记、性能等级与备注分离，缺少新标记时兼容原检测。

本轮覆盖MPfix及性能跟踪器配置标签／说明、五项提示、状态页、图表与历史诊断解释；后续扩展主要为编辑器固定文案及外部模组自己的译文。物品／液体等游戏内容名称继续使用游戏及其模组的本地化，不能通过翻译UI改变游戏语言。

## 已实现架构与后续扩展

1. Shared提供DdenLocalization与DdenTextCatalog。管理器使用文本ID；两模块按完整原文／格式模板精确映射。资源加载一次，不替换用户文字片段，不在GUI内逐次读取文件。
2. 提供“取文本、带参数格式化、语言变化通知”能力。切换时只清文本／尺寸相关缓存，重新计算滚动高度、列宽与工具提示；不重新安装补丁、不重连、不触发存档写入。
3. 配置显示层映射原始Section／Key到文本ID，DdenDocs也用同一目录。BepInEx cfg的原键保持不变；英文模式只改变可见标题和说明，原配置文件不自动翻译或迁移。
4. 英文长句使用测宽、换行或提示框，不能只依赖中文固定宽度。已绘制图表的说明与事件记录应保存稳定事件ID／参数，再按当前语言显示，避免切换前后的记录混在两种语言中。
5. 缺英文译文回退中文，并在开发检查中报告缺失；参数不匹配时安全回退，不抛到Unity。文案ID仅用于内部，不显示给玩家。

## 身份与多人边界

- 语言是**本机界面偏好**，不进入MPfix的主机权威白名单，不由主机覆盖；客机采用主机修复配置后仍可选择自己的语言。
- 不改cfg键、插件GUID、存档字段、物品ID、SteamID、频道、报告格式或伤害逻辑。搜索同时可接受游戏当前名称、另一语言目录名称（已有时）与稳定ID。
- 不翻译玩家名字、玩家输入、原始JSON键、物品自定义名与上游日志。技术日志保留稳定事件码／字段，必要时另外输出选择语言的说明。
- 无芯片的规则说明与伤害补倍率说明在两份语言表中须有对应词汇，避免英文又写成“cosmetic only”或“guaranteed recalculation”。

## 外部模组与独立模式

L1零引用约定继续可用，旧模组只交ConfigEntry时原样显示其说明，不承诺自动翻译第三方内容。可选DdenConfigMetadata、DdenLocalize及DdenSetLanguage已按显示规范v1接入，旧成员签名保留，缺译／缺标记回退。

ET-Fix不能因双语而增加Shared硬依赖。可选方案是在独立模组保留自己的小文本目录和语言配置，管理器有能力时通过可选反射传递“当前显示语言”，无管理器时仍按本机设置运行；需先明确谁管理临时显示偏好，不能把运行配置一并覆盖。管理器侧通知桥已实现；本轮未改ET-Fix或其它外部模组源码。

## 分步落地与验收

当前语言目录、管理器选择、MPfix、性能解释及外部可选桥已实现；编辑器与外部模组自身翻译留待后续。文档可另建英文玩家README并互链，技术文档是否全译由后续范围决定；本轮不建立占位英文文档冒充已翻译。

验收至少包括：两语言随时切换／重启持久化；不同DPI与窄窗口不溢出且滚动触底；旧cfg无需迁移；实验性显式false覆盖旧前缀，缺省标记回退；性能等级与备注分开翻译；主客机不同语言联机正常且主机模式不锁语言；游戏中英文物品名与用户文本不被改写；缺译文／参数失配可回退；没有管理器时独立模组仍加载；切换不发伤害消息、不改存档、无持续逐帧文本解析开销。
