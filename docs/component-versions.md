# 组件版本与适配校对

各组件独立维护产品版本，不再使用统一的`DdenVersion`属性。Shared产品版本、Shared API代际、管理器产品版本分别记录，不能互相替代。

| 组件 | 当前产品版本 | 说明 |
| --- | --- | --- |
| DDEN.Shared | 2.0.0 | 公共API代际为v1；`DdenApi.CurrentVersion`及程序集`DDEN.ApiVersion`元数据均为1 |
| DDExcNet管理器 | 2.0.0 | 内置本次已知模块最新版本目录，支持API v1 |
| MPfix | 1.7.4 | 声明管理器≥2.0.0、Shared≥2.0.0、API v1 |
| 性能跟踪器 | 2.0.0 | 声明管理器≥2.0.0、Shared≥2.0.0、API v1 |
| 存档编辑器 | 2.0.0-alpha | 声明管理器≥2.0.0、Shared≥2.0.0、API v1 |

版本由各组件自己的csproj和插件声明维护。程序集数字版本采用四段数字，例如`2.0.0.0`。当前BepInEx加载器不接受`2.0.0-alpha`作为BepInPlugin版本，其Version会为空；因此编辑器插件加载声明使用`2.0.0`，csproj发行版本、AssemblyInformationalVersion和IDdenModule.Version保留`2.0.0-alpha`。管理器总览及模块页展示含alpha的发行版本，不能仅根据加载器的数字版号称其为正式版。

## 模块分别声明管理器和Shared要求

内部模块可选实现`DDEN.Shared.IDdenModuleVersion`，不修改已有IDdenModule契约：

```csharp
public string MinimumManagerVersion => "2.0.0";
public string TestedManagerVersion => "2.0.0";
public string MinimumSharedVersion => "2.0.0";
public string TestedSharedVersion => "2.0.0";
public int RequiredSharedApiVersion => 1;
```

- `MinimumManagerVersion`：最低管理器产品版本，包含该版本，显示为≥。
- `TestedManagerVersion`：模块作者声明校对过的管理器版本，用于说明，不是最高支持版本。
- `MinimumSharedVersion`：最低公共层产品版本，独立比较，不能因为API相同或管理器已更新就忽略。
- `TestedSharedVersion`：模块作者声明校对过的公共层产品版本，与管理器校对版本分开显示。
- `RequiredSharedApiVersion`：要求的API代际。正整数要求与运行公共层API相同，0表示未声明，不是Shared产品版本号。

未提供的字符串可返回null／空，未声明API返回0。未实现接口，或全部要求均为空／0时免检，不从插件名称或已知模块ID猜测要求。外置L1配置块不经过此版本检查，不新增强制Shared引用，也不把其DdenConfigMetadata显示标记当作版本声明。

例如管理器2.0.0、Shared1.9.9、API v1，仍不满足上述模块的Shared≥2.0.0要求；管理器1.9.9、Shared2.0.0则只提示管理器过旧。Shared2.1.0／API v1不会仅因产品版本比已校对版本新而被判为不兼容；API代际不同会单独提示。两者同时发放也始终分别读取运行版本与校对。

## 管理器如何显示

管理器自身的`ModuleVersionCatalog`记录当前已知最新版本：mpfix=1.7.4、perf=2.0.0、saveeditor=2.0.0-alpha，Shared记录版本为2.0.0。目录随管理器源码／发布更新，不联网查询，也不会把安装中的未知新版本反过来写成“已知最新”。

| 结果 | 显示 |
| --- | --- |
| 等于管理器记录版本 | 与记录最新一致 |
| 低于记录版本 | 低于记录最新，提示可升级模块 |
| 高于记录版本 | 高于记录版本；不冒充已校对，也不判为过旧 |
| 有要求但模块ID未收录 | 管理器尚未收录；适配要求仍独立检查 |
| 版本格式不能识别 | 无法校对；不显示为最新 |
| 无版本要求／L1外置配置 | 免检，不产生适配警告 |

总览恢复原两行卡片（内置模块56px，管理器及外置配置50px），发行版本保留在标题旁；记录版本比较、两组最低／已校对版本及API统一放入整卡悬停详情，不增加第三行。左侧全高竖线：版本与记录不一致、要求未满足或运行问题为红；正常加载／待用为蓝；明确正在工作为绿。高于记录版本也标为待核对，详情明确说明是新版，不称其为过旧。模块页面标题及独立窗口说明适配范围，单独配置页显示要求。低于最低管理器／Shared版本、API代际不符或要求格式错误时有醒目提示；管理器关闭时也会提示打开面板核对。管理器自身卡片分开显示管理器、实际Shared版本与API代际。

这些提示不修改配置、停用模块、覆盖主机设置或借用“忽略环境版本”开关。原游戏／MP环境版本闸门维持原行为。模块过旧与管理器／Shared不适配是两项独立结果：模块可以是记录中的最新版，同时要求更高的管理器或Shared版本。

模块发布元数据在登记时／首次读取时缓存，模块注册中心Changed事件使缓存失效；不逐帧反射或读取磁盘。正常更新DLL需重启游戏，不支持在运行中替换DLL热更新。坏的可选版本getter隔离为“声明无效”并缓存，不逐帧重试。切换语言只刷新提示文字／布局。

## 比较与维护规则

数字版本允许1至4段，缺少的段按0处理，因而2、2.0、2.0.0和2.0.0.0等价。支持v前缀、SemVer预发布段及构建元数据；构建元数据不参与先后比较，预发布版低于同号正式版，alpha.2低于alpha.10。非法格式明确标未知，不能用字符串字典序比较1.7.10与1.7.4。

发布某个模块时更新自身项目版本及加载器版本，并按实际校对结果更新两组要求和API代际。发布管理器时更新自身项目／插件版本、ModuleVersionCatalog.ManagerRelease、支持API和内置记录表，离线检查校验记录与当前交付组件一致。Shared的产品版本更新不要求所有模块一起升号；API不兼容变化应另行调整API代际。

`scripts/release.ps1`包版本默认取管理器项目，各DLL按自身项目的数字程序集版本及产品发行元数据校验，不再要求五个DLL同号；也会区分Alpha与同数字号正式版。本次仅适配脚本代码，未运行打包、上传或部署。

离线检查覆盖产品版本、API、两个最低要求分别不足、缺省免检、Alpha／数字比较、缓存及实际编译元数据。提示的游戏内布局及真实联机仍需另行验收。显示接口和旧外部模组兼容约定见[管理器显示规范](manager-ui-contract.md)。

## 总览运行状态

可选Shared接口`IDdenModuleActivity.IsRunning`提供实际活动状态；开关打开不等于正在工作。MPfix按已启用且真实联机判断，性能跟踪器按正在采样判断，暂停／停止为待用。未提供活动状态的工具或L1外置配置默认按已加载显示蓝线，不从中文／英文摘要猜测状态。版本、依赖或健康问题优先红线；管理器总览正在绘制时自身为绿线。此接口为显示状态，不改变配置或功能行为。
