## 统一口径

- v1.7.1已移除并放弃玩家离场物品剔除广播；该方案实测无效，不再列为已修复或待验收功能。掉帧问题仍存在，原背包流程由Together负责。

- 无芯片核心现象：**主机开无芯片，客机仍有芯片**，涉及实际游戏规则和玩家状态。
- 非激进伤害修复：**补齐主机漏算的世界伤害倍率**；主机使用攻击客机的远端角色状态，不保证其他状态差异自动消失。
- 当前工作树已移除激进上报与穿戴兜底，只保留三分支基础世界倍率补算；旧开关不再生效，历史报告机制不能当作现有能力。
- 引擎版本不是游戏版本；版本检查目前针对Together 5.5.4，不等于对所有游戏更新均已验证。
- 代码检查、离线模拟、游戏内菜单与真实多人验收分别记录；不把“尝试修复”写成保证解决。
