## 适用版本

- 游戏：Casualties Unknown（Unity 2022.3）
- 加载器：BepInEx 5
- 联机框架：Together / CasualtiesMP 5.5.x（5.5.3、5.5.4 已验证）
- 前置：CUCoreLib（联机部分需要）
- 本包版本：随 Release 标题

## 安装

1. 先装好 BepInEx 5，并让它成功跑过一次（游戏目录下出现 `BepInEx/` 文件夹）；
2. 把压缩包里的 dll **一起**放进 `BepInEx/plugins/DDEN/`，不要拆开、不要改名；
3. 进游戏按 **F11** 打开界面（若 F11 被别的模组占用会自动换键，并在界面里提示）。

联机修复需要 CUCoreLib 与 Together / CasualtiesMP；缺了也能进游戏，只是联机那部分不生效。

## 模块说明

| 模块 | 作用 | 必需 |
| --- | --- | --- |
| **管理界面**（`DDExcNet-CUmodM.dll`） | 所有功能的开关与说明都在这一个窗口里：总览、兼容性检查、全部配置、各模块自己的页面、关于页；也能自动识别**别人做的模组**，把它们的设置一起列进来改。 | 是 |
| **多人修复**（`DDEN.MPfix.dll`） | 联机毛病的主修集合，清单见下一节。 | 是（联机） |
| **存档编辑器**（`DDEN.SaveEditor.dll`） | 在界面里直接看/改存档：角色数值、物品、进度；支持 QoL 多存档位；改错自动留备份。 | 否 |
| **性能跟踪器**（`DDEN.NetPerfTracker.dll`） | 单独一页「性能分析」：帧数、CPU、物理压力、世界对象数量画成曲线，可鼠标悬停读数，并写日志。**只观察，不改游戏**；遇到掉帧时开着它把日志发给作者即可定位。 | 否 |
| **公共层**（`DDEN.Shared.dll`） | 上面几个模块共用的基础部分，玩家不用管，也不要删。 | 是 |

## 修复的功能模块及其对应的核心开关说明

开关都在界面的「全部配置」里，按「分类 / 名称」找；下表只列**核心**那一个到几个，其余保持默认即可。

| 修复的功能 | 修了什么 | 核心开关（默认） |
| --- | --- | --- |
| 无芯片同步 | 联机时「无芯片模式」以主机为准，本机自动跟随（HUD、名牌、语音一起变） | `无芯片同步 / Enabled`（开）· `无芯片同步 / WatchdogSeconds`（30 秒核对一次） |
| 联机生成与登记 | 模组加的物品在联机能真正造出来，并且其他人也看得见 | `联机合成 / FixModItemCraftSpawn`（开）· `联机合成 / RegisterSpawnedItemsOnHost`（开） |
| 穿戴兜底 | 客机穿上的装备两边显示一致，不会出现「东西跟着人跑」 | `穿戴兜底 / Enabled`（开）· `穿戴兜底 / GraceSeconds`（1.5 秒后开始核对） |
| 物品物理保险 | 丢在地上的物品不再穿过墙体与地板往下消失 | `物品物理 / GuardDropPhysics`（开） |
| 挖块修复 | 血量不再「掉一截又弹回」、挖掉的方块不再重生 | `联机修正 / SyncBlockBreak`（开）· `联机修正 / BlockDamageRatio`（6 倍）· `联机修正 / BlockBreakMinFraction`（0.5） |
| 商人商品表对齐 | 打开交易界面时重新对齐一次商品表，避免「付了钱不发货」 | `联机修正 / TraderSnapshotOnOpen`（开） |
| 掉线后的掉帧 | 掉线遗留的异常物品先原地停下；再被写活（原地闪烁）就交给联机框架清掉；主机仍认得的物品一律不碰 | `联机修正 / CleanGhostItems`（开）· `联机修正 / CleanGhostItemsMaxPerSession`（400） |

另有一个纯娱乐开关，不影响上面任何修复：`娱乐 / 道生一 一生二`（联机在商人那儿买东西多送一件，默认**关**）。
