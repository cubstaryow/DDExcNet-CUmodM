# DDExcNet v1.8.5 模组说明

## 适用版本

- 游戏：Casualties: Unknown（Unity 2022.3，Windows / Mono）
- 加载器：BepInEx 5（win_x64）
- 联机框架：Together / CasualtiesMP **5.5.5**（本版按它校对；5.5.4 及更早不再作为核对目标）
- 前置：CUCoreLib 1.1（联机相关功能需要）

> **联机两端必须同版**。各组件版本独立，管理器会按每个模块自己声明的最低/已核对管理器与公共层版本做判定，版本不符会直接列出，不再要求所有 dll 同一个号。

## 本版变更（1.8.5）

- **适配 Together 5.5.5**：按新版本的接口与运行就绪判定重新校对；联机相关功能会先确认 Together 真初始化、CUCoreLib 接口真可用，才开始工作。
- **新增可选深层诊断模块** `DDEN.NetPerfTracker.Enhanced`（0.2.1-alpha）：给性能跟踪器补 Together / LES / 物体更新的纯计时钩子，**默认关闭**，只做计时，不改逻辑。
- 多人修复合集到 **1.8.5**：名称显示、合成失败补救、物品物理、商人商品表、主机权威配置、伤害补倍率的范围不变；本版修的是 Together 5.5.5 下的兼容与判定问题。
- 管理器到 **2.1.0**：按模块独立版本显示「已安装 / 最低要求 / 已核对」，总览卡片带状态竖线；快捷入口仍为管理器内页面，不再有模块独立窗口。
- 龙域武库（LoongNova，龙化装备包）模块到 **1.1.0**；单位清单管理器 **0.1.2-alpha**；存档编辑器 **2.0.1-alpha**；公共层 **2.0.1**。

## Nexus 分发说明

N 网分两个包：主包 `DDExcNet-1.8.5-Nexus.zip` 含 DDEN 公共层、管理器、多人修复、性能跟踪器、深层诊断、存档编辑器、单位清单管理器；
**龙域武库 `DDExcNet-1.8.5-Nexus-LoongNova.zip` 单独一个包**（只含 `DDEN.LoongNova.dll`），想用龙域武库的人另装它，避免重复安装。
## 组件与主要功能

| 组件 | 用途 |
| --- | --- |
| DDEN.Shared.dll | 公共层，其他 DDEN 组件依赖它 |
| DDExcNet-CUmodM.dll | 统一管理器：总览、兼容性、全部配置、模块页 |
| DDEN.MPfix.dll | 联机修复：无芯片同步、伤害补倍率、合成补救、物品物理、商人快照、名称显示、主机权威配置 |
| DDEN.NetPerfTracker.dll | 性能读数：帧耗时、2D 模拟、物品状态、突变记录 |
| DDEN.NetPerfTracker.Enhanced.dll | 可选：深层计时诊断（Together / LES / 物体更新），默认关闭 |
| DDEN.SaveEditor.dll | 可选：图形化存档编辑器 |
| DDEN.UnitListMgr.dll | 可选：单位／物品清单管理器（查看、生成、滤镜、轮盘） |
| DDEN.LoongNova.dll | 龙域武库（龙化装备包）：龙灼线束／龙息单元／重力腰带／龙化工具与配方，含联机适配 |

## 实验性模块声明

**存档编辑器（DDEN.SaveEditor）、单位清单管理器（DDEN.UnitListMgr）标记为实验性模块：主动使用导致存档损坏概不负责。**
深层诊断模块（DDEN.NetPerfTracker.Enhanced）同为实验性、默认关闭，只用于排查，不建议长期开启。

用前请自行备份存档；不放心就不要放这三个 dll，其余模块不受影响。

## 默认值

- 默认开：无芯片同步、合成补救、三条伤害补倍率、丢弃物解除穿墙、名称显示
- 默认关：商人商品表对齐、主机权威配置、深层诊断、购买多给一件（「道生一 一生二」）

每行设置鼠标悬停可看到「功能 / 修复的问题 / 解决方案 / 实验性 / 性能影响」五项。

## 安装与升级

关闭游戏后，把包内 dll 一起放进 `BepInEx/plugins/DDEN/`，替换同名文件，不要新旧并存。公共层必须保留；性能跟踪器、深层诊断、存档编辑器、单位清单管理器可按需选装。

`ET-Fix`、`JDI-DDEN`、`DS Tool Extension` 是独立外部模组，不随本包发布。

进游戏按管理器快捷键（默认 F11）打开面板，也可在控制台输入 `dden`；与其他模组撞键时管理器会自动换键并保存，以界面显示为准。

## 已知限制

- 界面默认中文，管理器可切 English；切换只影响管理器显示，不改游戏语言、配置键或联机设置。
- 伤害类修复只补主机漏掉的世界伤害倍率，主机与客机在种族、力量、工具或身体状态上差异较大时，血量仍可能跳。
- 客机退出后其他客机掉帧的问题本模组不再尝试处理，背包交回原版 Together 的保存／重连流程。
- 本版只做编译与离线检查，没有进行游戏内与真实联机验收；实际表现以双端实测为准。
