# DDExcNet v1.7.2 模组说明

> 本文按本地1.7.2工作树校对；版本提升、激进上报／穿戴兜底移除等代码尚未提交，本次文档提交不包含这些源码变更。实际已发布能力以对应提交和安装包为准。

## 当前工作树修订（待对应代码提交后发布）

玩家离场物品剔除广播方案经用户实测不能解决客机退出后其他客机掉帧的问题，现已移除并放弃此项修复。删除相关运行入口、频道和配置；旧cfg中的RelayGhostItems不再生效，主机权威配置也不能恢复它。原功能只在本地反编译目录保留备份，不随发布包分发。

当前工作树另移除激进伤害上报与穿戴兜底，并让名称显示跟随原MP刷新；发布说明不得继续宣传这些已移除机制。本版不再介入退出时的背包处理，交由原版Together流程；掉帧问题没有被本版解决，也未判定唯一根因。

## 组件与主要功能

| 组件 | 用途 |
| --- | --- |
| DDEN.Shared.dll | 公共层，其他DDExcNet组件依赖它 |
| DDExcNet-CUmodM.dll | 统一管理器及配置页 |
| DDEN.MPfix.dll | 无芯片同步、近战伤害、生成失败补救等多人修复 |
| DDEN.SaveEditor.dll | 可选图形化存档编辑器 |
| DDEN.NetPerfTracker.dll | 可选性能读数与突变记录 |

无芯片同步针对“主机开启，客机依旧有芯片”的实际规则差异。基础伤害修复补主机漏算的世界倍率，角色数值来自攻击客机在主机上的副本；判定仍走联机框架原本逻辑。

合成补救只在主机生成失败时尝试；正常成功不额外给一份。“道生一 一生二”仍为默认关闭的独立娱乐功能。实际丢弃碰撞保险、商人快照、名称显示修复及临时主机权威配置保留。名称修复只使用游戏字体，缺字显示?。

编辑器支持弹药、电池、混合液体等字段，修改先暂存后保存；不自动改变禁用成就标记。性能分析区分步／帧与准确计时，数量及等待仅为线索，不能单独证明CPU/GPU瓶颈。

## 安装与限制

关闭游戏后将五个DLL放入`BepInEx/plugins/DDEN/`，替换准确同名文件，不重复安装；公共层保留，编辑器和跟踪器可按需选装。主机和各客机用同版。默认F8打开管理器，冲突时以实际设置为准，也可控制台输入dden。

需BepInEx 5（Windows Mono）；MPfix目标Together / CasualtiesMP 5.5.4，相关同步功能还需兼容CUCoreLib。缺少前置的功能停用并显示原因。ET-Fix与JDI-DDEN独立发布，不包含在本包中。游戏内界面仍主要为中文，English切换未实现。
