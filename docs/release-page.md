# DDEN v1.6.0 模组说明

## 功能与适用范围

DDEN为《Casualties Unknown》提供统一管理器、多人修复、可选存档编辑器和性能跟踪器。多人修复当前核对Together / CasualtiesMP **5.5.4**；需要的社区前置按具体功能检查。未知版本会提示并停用相应修复，忽略检查不等于已验证兼容。

**无芯片同步的核心问题是：主机开启无芯片模式，客机依旧有芯片。** 修复将主机状态应用到客机规则与玩家状态；主机关闭后也能同步恢复，不是只修HUD、名牌或语音。

**伤害修复有两种模式**：默认只补主机结算客机近战时漏掉的世界伤害倍率，使用的是该客机在主机上的角色状态。激进模式只对已开启分支生效：方块碎后批量上报、主机检查后补差值；单位和角色随原攻击消息上报，主机校验后在原攻击中结算一次。不同种族／力量等副本差异仍需核对，不能保证所有目标或所有回弹都被覆盖。大量高速挖掘仍有开销和确认等待。

其它功能包括合成生成失败时补救、可选穿戴兜底、实际丢弃时的碰撞保险、商人商品表重取、主机确认后清理客机离场遗留副本，以及默认关闭的名称显示尝试修复。正常合成不额外给一份；默认关闭的“道生一 一生二”是独立娱乐功能。

## 管理与工具

- 管理器默认 **F8**，冲突时会自动选择其它键，以实际设置为准；控制台输入 `dden`也可打开。
- 主机权威配置默认关；双方采用且收到有效主机配置时，客机临时锁定其它项，退出或取消后恢复本机设置。主机始终可以编辑。
- 编辑器支持弹药、子弹数、电池状态和多种液体，先暂存再确认保存；不会自动改禁用成就标记。
- 性能跟踪器区分实际帧耗时、可用2D计时、物品状态与自身开销；步／帧不是物理压力，等待计时不能单独证明GPU瓶颈。突变带时间和解释，日志手动导出。

## 安装与升级

关闭游戏后，将选用的组件放入 `BepInEx/plugins/DDEN/`，保留DDEN公共层。联机各端用同一版；多人修复需要Together，无芯片／合成补救等还需CUCoreLib。缺依赖的功能关闭并说明原因，补齐重启后可手动重新开启。

完整包另附 **ET-HeatingCageFix（ET 加热笼修复）**：需要Enhanced Tools与CUCoreLib，可独立安装，不强制依赖DDEN。**旧 `CageFix.dll`先移除，只留新 `ET-HeatingCageFix.dll`**；原配置延续。尝试修复笼子关闭后仍腐坏／仍算热源的问题，保存和多人开关行为仍需实测。
