## 适用版本

- 游戏：Casualties Unknown（Unity 2022.3）
- 加载器：BepInEx 5
- 联机框架：Together / CasualtiesMP **5.5.4**（本版按它逐项核对过）
- 前置：CUCoreLib（联机部分需要）
- 本包版本：随 Release 标题

> **版本核对**：本版是针对联机组件 5.5.4 做的修复。若你的联机组件版本不同，多人修复会先停手，
> 主界面会提示「DDEN未校对此环境版本兼容性，需要打开面板处理！」。
> 确认要在这个环境下用，就在界面「总览 → 忽略核对环境版本」打开它；改完立即生效。

## 安装

1. 先装好 BepInEx 5，并让它成功跑过一次（游戏目录下出现 `BepInEx/` 文件夹）；
2. 把压缩包里的 dll **一起**放进 `BepInEx/plugins/DDEN/`，不要拆开、不要改名；
3. 进游戏按 **F11** 打开界面（若 F11 被别的模组占用会自动换键，并在界面里提示）。

联机修复需要 CUCoreLib 与 Together / CasualtiesMP；缺了也能进游戏，只是联机那部分不生效。

## 模块说明

| 模块 | 作用 | 必需 |
| --- | --- | --- |
| **管理界面**（`DDExcNet-CUmodM.dll`） | 所有功能的开关与说明都在这一个窗口里：总览、兼容性检查、全部配置、各模块自己的页面、关于页；也能自动识别**别人做的模组**，把它们的设置一起列进来改。 | 是 |
| **多人修复**（`DDEN.MPfix.dll`） | 联机毛病的主修集合，清单见下一节。 | 是（联机） |
| **存档编辑器**（`DDEN.SaveEditor.dll`） | 在界面里直接看/改存档：角色数值、物品、进度；支持 QoL 多存档位；改错自动留备份。 | 否 |
| **性能跟踪器**（`DDEN.NetPerfTracker.dll`） | 单独一页「性能分析」：帧数、CPU、物理压力、世界对象数量画成曲线，可鼠标悬停读数。**只观察，不改游戏**；采样开关就是它的主开关，关掉后整块设置变灰；数据只在内存里，点「导出日志」才写文件。 | 否 |
| **公共层**（`DDEN.Shared.dll`） | 上面几个模块共用的基础部分，玩家不用管，也不要删。 | 是 |

## 修复的功能模块及其对应的核心开关说明

开关都在界面的「全部配置」里，按「分类 / 名称」找；下表只列**核心**那一个到几个，其余保持默认即可。

| 修复的功能 | 修了什么 | 核心开关（默认） |
| --- | --- | --- |
| 无芯片同步 | 联机时「无芯片模式」以主机为准，本机自动跟随（HUD、名牌、语音一起变） | `无芯片同步 / 启用（Enabled）`（开）· `核对间隔秒（WatchdogSeconds）`（30 秒） |
| 联机生成与登记 | 模组加的物品在联机能真正造出来，并且其他人也看得见（登记是自动的，没有开关） | `联机合成 / 修“无法生成物品”（FixModItemCraftSpawn）`（开） |
| 穿戴兜底 | 客机穿上的装备两边显示一致，不会出现「东西跟着人跑」（默认关闭，需要时再开） | `穿戴兜底 / 启用穿戴兜底（Enabled）`（关）· `一局最多处理几次（MaxPerSession）`（20） |
| 物品物理保险 | 你亲手丢出去的物品不再穿过墙体与地板往下消失（只管这一下，不挪位置、不改物理模式） | `物品物理 / 丢弃物解除穿墙（GuardDropPhysics）`（开） |
| 挖方块 | 血量不再「掉一截又弹回」、挖掉的方块不再重生 | `联机修正 / 修“挖方块”-伤害重算（SyncBlockBreak）`（开） |
| 打箱子/植物/动物 | 打这些单位时血量不再「掉一下又弹回」 | `联机修正 / 修“打箱子/植物/动物”-伤害重算（SyncBuildingDamage）`（开） |
| 打角色/肢体类敌人 | 尝试补齐客机近战攻击时主机漏算的伤害 | `联机修正 / 修“打角色/肢体”-伤害重算（SyncBodyDamage）`（开） |
| 激进重算（实验性） | 只处理已开启修复的分支。碎块分批上报、分帧补齐；单位和角色随原有攻击消息上报。**默认关**，多人高速挖掘仍需实测帧数和确认等待时间 | `联机修正 / 挖掘修复-激进（实验性 · ⚠帧数影响）（AggressiveConverge）`（关）· `挖块判定门槛-仅激进时生效（BlockBreakMinFraction）`（0.5） |
| 商人商品表对齐 | 打开交易界面时重新对齐一次商品表，避免「付了钱不发货」 | `联机修正 / 打开商人时对齐商品表（TraderSnapshotOnOpen）`（开） |
| 掉线后的掉帧 | 主机把退场玩家的物品收进存档时，把清单广播给所有客机，客机据此删掉本地那份「没人管、一直下坠」的副本 | `联机修正 / 离场物品广播清理（RelayGhostItems）`（开） |

另有两个非修复类开关：`娱乐 / 道生一 一生二（DoublePurchase）`（商人购买必定给两个、造物品有 20% 概率多一件，默认**关**）；
`联机修正 / 商人界面不再刷“prefab 为空”（QuietTraderUIModItems）`（只是把误报日志静音，默认开）。

**新界面说明**：每条开关只写一行「它做什么」，把鼠标移到那一行会展开完整五项（功能 / 修复的问题 / 解决方案 /
实验性 / 性能影响）；左侧色条表示状态（蓝=开、灰=关、橙=实验性）。多人修复页顶部有「运行一览」，
逐项显示 运行中 / 监控中 / 关 / 错误。
