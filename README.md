# DDExcNet

> 本项目源自于朋友间的小打小闹，仓库公开是方便其他人参阅，但我不太可能将大量精力放在维护此仓库上。

《Casualties Unknown》的模组合集，包含统一管理器、多人修复、存档编辑器、性能跟踪器和物品工具。作者：**cubstaryow**。

多人修复以 Together / CasualtiesMP **5.5.5** 为当前核对目标。构建及离线检查通过不代表所有功能已经完成真实联机验收；各项限制见下文。

## 多人修复解决什么问题

| 遇到的问题 | 当前处理方式 |
| --- | --- |
| **主机开启无芯片模式，客机依旧有芯片** | 将主机的无芯片状态应用到客机的实际规则和本地玩家状态；主机关闭时也可同步回有芯片。不是只改界面或名牌 |
| 客机挖块、近战打单位时血量先减少又回升 | 补齐主机结算漏掉的世界伤害倍率；判定仍走联机框架原本逻辑 |
| 联机合成模组物品提示“无法生成物品” | **实验性**：清除失效的模板缓存并让前置重建，只在主机未生成结果时补救，正常成功时不额外发放 |
| 玩家丢弃物品后，物品因碰撞关闭而下坠 | 在实际丢弃时尝试恢复合适的碰撞体；不移动物品，不保证处理所有穿墙原因 |
| 打开商人后商品表不同步 | 向主机重新请求商品表，尝试减少交易不一致（默认关闭，需要时在管理器里打开） |
| 一个客机退出后，其他客机持续掉帧 | 当前通过性能跟踪器收集证据；客机背包同步重试补丁已移除，不修改 Together 原重试行为 |
| 中文名字成问号、数字，或主机名字为空 | 名称显示修复；跟随原MP名称显示刷新，使用游戏已有字体，缺字显示 `?` |

### 伤害修复怎么选

方块、箱子／植物／动物类单位、角色／肢体各有一个修复开关。这里的分类按游戏内部攻击路径划分，不能保证覆盖所有生物的所有攻击。

- 主机用该客机角色在主机上的状态结算，**补齐漏算的世界伤害倍率**；不会换成主机自己的种族、力量或工具，也不会额外发起第二次伤害。
- 不同种族、力量、工具或身体状态在两端仍有差异时，单补倍率可能不足——它只修「漏乘的倍率」，不承诺所有回弹都消失。

基础伤害补算在主机执行；联机各端建议使用同一修订，并核对分支开关。详细边界见 [功能说明](docs/features.md)。

另有默认关闭的娱乐功能“道生一 一生二”：商人购买额外给一件，其他生成有20%概率额外给一件。它与合成失败补救独立。

## 管理器与可选工具

管理器默认 **F11** 打开；冲突时依次尝试 F10 至 F1 并保存，F12 留给 Steam 截图，以实际设置为准。也可在游戏控制台输入 `dden`。

- **总览、兼容性、全部配置**：查看状态、依赖、快捷键冲突并修改设置；适配的外部模组也有独立配置页。
- **主机权威配置**：默认关闭。主机和客机都选择采用时，客机临时使用主机设置，显示“（主机权威模式）”。主机仍可修改；客机仅保留总开关和采用选项可编辑，退出联机或取消采用后恢复本机配置。
- **存档编辑器**：物品、角色、世界与进度分区。支持弹药数量与状态、电池、多种液体等，修改先暂存，确认后保存；不会自动改动禁用成就标记。它是可选工具，保存前请确认正在操作的存档。
- **性能分析**：采样主开关默认关闭，CPU阶段计时默认开启（仅随采样运行）。分开显示帧耗时、可用的2D模拟计时、物品状态和工具自身开销。低帧有说明；“告警与联机反馈”页可分别开启波动告警和Together探针，均默认关闭。缺失计时明确标记，不把物理步数当作物理耗时。日志只在手动导出时写盘。独立可选的“性能跟踪器增强”提供逐函数计时，需同时开启Together探针与深层计时；默认关闭，详见[使用说明](docs/perf-tracker.md)。

所有功能页通过管理器打开；物品生成轮盘保留快捷键。详细日志统一在管理器配置，安装性能跟踪器时使用其日志通道。关于页列出全部组件及安装状态。

缺少功能所需前置时，对应功能关闭并显示原因；采用主机配置不能绕过缺失依赖。补齐并重启后可手动重新开启。

## 安装与升级

本包包含六个 DDExcNet 组件（含 Shared 和 UnitListMgr）；DLL 和配置仍沿用 DDEN 名称。ET-Fix 与 JDI-DDEN 为独立外部模组，不随本包发布。旧版本配置中的 RelayGhostItems 不再读取；无需为升级清空配置或删除存档。

1. 安装 BepInEx 5；使用多人修复还需安装 Together / CasualtiesMP。无芯片同步、合成补救等功能另外需要 CUCoreLib。
2. 将完整包中的DDEN组件放入游戏的 `BepInEx/plugins/DDEN/`。公共层是DDEN组件的必要依赖；存档编辑器、性能跟踪器和物品工具可按需选择。
3. 关闭游戏后再替换旧文件，避免同一插件存在多份。主机与各客机使用同一版。
4. 进游戏核对状态和实际快捷键。多人组件版本不符时，多人修复会停用并提示；忽略版本检查不代表已验证兼容。

**ET-Fix（独立ET修复）**是**独立发布的另一个模组**，不在本包里：需要 Enhanced Tools 与 CUCoreLib，可不安装 DDEN。它尝试修正关闭后仍腐坏、仍可作为合成热源的问题，并支持记住开关、联机确认。升级时先移除旧 `CageFix.dll`，只保留新 `ET-Fix.dll`；原配置继续使用。见 [独立说明](src/外部mod/ET-Fix/README.md)。

**JDI-DDEN（工具撬石果，独立发布、不在本包中）**：把带 `tool` 标签的物品拖到封闭石果上即可打开；单机/主机本地执行，客机通过 Together 请求主机，替代原版 StonefruitOpener。需 Together / CasualtiesMP（软依赖），见 [独立说明](src/外部mod/JDI-DDEN/README.md)。
