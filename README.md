# DDEN · CUmod

《Casualties Unknown》的模组合集：一个统一的管理器，加上一套专治**联机不同步**的修复。

> 作者：**cubstaryow**
> 目前对得上《Casualties Unknown》2022.3 版游戏，以及联机框架 Together / CasualtiesMP 5.5.3 / 5.5.4。

## 它修好了什么

装完之后，下面这些联机常见毛病会消失或明显缓解：

| 你会遇到的毛病 | 现在的表现 |
| --- | --- |
| 主机改了「无芯片」设置，客机界面变了但名牌、附近语音还是旧的 | 以主机为准，客机自动跟上；万一被改动，会自己核对回来 |
| 联机合成模组加的物品时提示无法生成物品 | 能正常做出来，其他人也看得见；「过一层才能合成」的情况也不必再换层 |
| 客机明明穿上了装备，主机眼里它还在地上、甚至跟着人跑 | 主机认出那件装备并穿对位置，两边看到的一致 |
| 丢出去的东西穿墙、掉进地图外面 | 丢出的物品会正常落地 |
| 客机挖掉方块又长回来，挖的时候方块血量还忽上忽下 | 两边血量与破坏结果一致；方块按正常流程碎掉，掉落照旧 |
| 客机付钱买了商人的东西却没拿到 | 每次打开商人界面都会重新对齐商品表 |
| 一台客机掉线后，另一台客机卡成幻灯片 | 掉线遗留的异常物品会被原地停下，不再一直拖着物理算 |
| （娱乐）想买一件拿两件 | 「道生一 一生二」开关，默认关闭 |

每一项的**具体原因和我们怎么修的**写在 [docs/features.md](docs/features.md)，
这里只列你会感受到的结果。

## 装了之后你会看到什么

按快捷键打开管理器（默认 **F8**；如果和别的模组撞键，会自己换一个空闲键并记到设置里）：

- **总览**：每个模组一张卡片，显示它是正常工作还是功能受限。
- **兼容性**：装了什么模组、有没有互相抢快捷键、有没有旧版本残留文件。
- **全部配置**：所有模组的设置集中在一页，按模组和分组排列，改完立刻生效。
- **其它模组的设置**：没做适配的模组，只要它肯把设置交出来，也能在这里统一改。
- **关于 DDExcNet**：世界观出处、作者、各个组件的版本。

设置也可以直接改游戏目录下的 `BepInEx/config/com.dden.cumodm.cfg`、`com.dden.mpfix.cfg`。
控制台也能输入 `dden` 打开管理器。

## 安装

1. 游戏先装好 **BepInEx 5**（游戏目录下会出现 `BepInEx/` 文件夹）。
2. 把包里的文件**一起**放进 `BepInEx/plugins/DDEN/` —— 它们必须放在同一个文件夹里，别拆开。
3. 想用联机相关的修复，还需要装联机框架 **CUCoreLib** 与 **Together / CasualtiesMP**。
   没装也能进游戏，只是联机那部分修复不会生效，管理器里会标成「功能受限」。

> 存档编辑器是**可选组件**，默认不含。需要图形化改存档的版本请单独取（或自行构建时带上）。

## 设置建议

默认值已经调到「装上就能用」，一般不用动。只有两种情况值得改：

- **用模组工具、或者把世界设置里的伤害倍率调高了**，却出现「怎么挖都挖不动」：
  把「联机修正 → 挖块伤害信任上限」从 6 倍再往上加一点。
- **觉得某条修复太保守/太激进**：每个修复都有独立开关，关掉就完全退回原版行为。

## 构建

需要 .NET SDK 10。仓库里只有一处本机路径要改：`Directory.Build.props` 里的游戏目录
（或用 `-p:GameDir=...` 传进去）。

```bash
dotnet build CUmod.slnx -v m     # 只编译
./scripts/build.sh               # 编译并部署到游戏的 plugins/DDEN
```

部署前**请先关游戏**，否则文件被占用会复制失败。构建与部署的细节、以及每个修复的坑，
都写在 [AGENTS.md](AGENTS.md) 里。

## 已知限制

- 联机部分的修复是针对上面写的联机框架版本逐点核对做的；框架大版本一换可能对不上，
  管理器会在日志里提示版本不符。
- 存档编辑器只改你点过的字段，**不会**自动动「禁用成就」标记，需要你自己在「进度/成就」页切。
- 反编译参考和构建产物都不会进仓库。

## 关于 DDExcNet

DDExcNet 是「幼龙云」所属「视界」世界观下的**龙域信息交换网络标准** —— 一套约定
「不同端口、不同实现之间怎么互相认出对方、怎么交换状态」的接口规范。
本仓库是它在《Casualties Unknown》里的落地实现：一个管理器、一套联机修复、一个可选的存档编辑器。
