# DDEN · CUmod v1.6.0

《Casualties Unknown》的模组合集，包含统一管理器、多人修复、存档编辑器和性能跟踪器。作者：**cubstaryow**。

多人修复以 Together / CasualtiesMP **5.5.4** 为当前核对目标。构建及离线检查通过不代表所有功能已经完成真实联机验收；各项限制见下文。

## 多人修复解决什么问题

| 遇到的问题 | 当前处理方式 |
| --- | --- |
| **主机开启无芯片模式，客机依旧有芯片** | 将主机的无芯片状态应用到客机的实际规则和本地玩家状态；主机关闭时也可同步回有芯片。不是只改界面或名牌 |
| 客机挖块、近战打单位时血量先减少又回升 | 默认补齐主机结算漏掉的世界伤害倍率；仍有差异时，可选用激进模式进一步核对客机结果 |
| 联机合成模组物品提示“无法生成物品” | 只在主机未生成结果时尝试补救，正常成功时不额外发放 |
| 客机穿上装备，主机却仍把它当作地上的物品 | 可选穿戴兜底，请主机确认该玩家与该物品；无法确定时保留现状，默认关闭 |
| 玩家丢弃物品后，物品因碰撞关闭而下坠 | 在实际丢弃时尝试恢复合适的碰撞体；不移动物品，不保证处理所有穿墙原因 |
| 打开商人后商品表不同步 | 向主机重新请求商品表，尝试减少交易不一致 |
| 一个客机退出后，其他客机持续掉帧 | 按主机确认的离线背包清单分帧清理客机遗留副本；不删除主机保存的背包，不处理未经确认的正常物品 |
| 中文名字成问号、数字，或主机名字为空 | 可选名称显示修复，仅改本机显示；使用游戏已有字体，缺字显示 `?`，实际多人效果待验证 |

### 两种伤害修复怎么选

方块、箱子／植物／动物类单位、角色／肢体各有一个修复开关。这里的分类按游戏内部攻击路径划分，不能保证覆盖所有生物的所有攻击。

- **默认模式（不开激进）**：主机用该客机角色在主机上的状态结算，补齐漏算的世界伤害倍率。不会直接换成主机自己的种族、力量或工具，也不会额外发起第二次伤害。
- **激进模式（默认关闭）**：只作用于已开启修复的分支。方块在客机挖碎后分批上报，由主机校验并补齐差值；单位与角色的客机计算结果附在原攻击消息中，由主机校验后用于这一次结算。
- 不同种族、力量、工具或身体状态在两端仍有差异时，单补倍率可能不足。激进上报也受主机校验限制，不承诺所有回弹都消失。
- 激进挖块采用分批发送、分帧处理；大量高速挖掘仍有开销，也可能增加确认等待时间。

两端请安装相同版本，并核对对应分支开关。主机只安装基础修复可以修正主机侧计算；需要客机上报的激进路径则要求双方启用。详细边界见 [功能说明](docs/features.md)。

另有默认关闭的娱乐功能“道生一 一生二”：商人购买额外给一件，其他生成有20%概率额外给一件。它与合成失败补救独立。

## 管理器与可选工具

管理器默认 **F8** 打开；快捷键冲突时会选择其他空闲键并保存，以实际设置为准。也可在游戏控制台输入 `dden`。

- **总览、兼容性、全部配置**：查看状态、依赖、快捷键冲突并修改设置；适配的外部模组也有独立配置页。
- **主机权威配置**：默认关闭。主机和客机都选择采用时，客机临时使用主机设置，显示“（主机权威模式）”。主机仍可修改；客机仅保留总开关和采用选项可编辑，退出联机或取消采用后恢复本机配置。
- **存档编辑器**：物品、角色、世界与进度分区。支持弹药数量与状态、电池、多种液体等，修改先暂存，确认后保存；不会自动改动禁用成就标记。它是可选工具，保存前请确认正在操作的存档。
- **性能分析**：分开显示帧耗时、可用的2D模拟计时、物品状态和工具自身开销。低帧及突变有说明；缺失计时明确标记，不把物理步数当作物理耗时。日志只在手动导出时写盘。

缺少功能所需前置时，对应功能关闭并显示原因；采用主机配置不能绕过缺失依赖。补齐并重启后可手动重新开启。

## 安装与升级

1. 安装 BepInEx 5；使用多人修复还需安装 Together / CasualtiesMP。无芯片同步、合成补救等功能另外需要 CUCoreLib。
2. 将完整包中的DDEN组件放入游戏的 `BepInEx/plugins/DDEN/`。公共层是DDEN组件的必要依赖；存档编辑器、性能跟踪器可按需选择。
3. 关闭游戏后再替换旧文件，避免同一插件存在多份。主机与各客机使用同一版。
4. 进游戏核对状态和实际快捷键。多人组件版本不符时，多人修复会停用并提示；忽略版本检查不代表已验证兼容。

**ET-Fix（ET 加热笼修复）**是包内独立可选模组：需要 Enhanced Tools 与 CUCoreLib，可不安装DDEN。它尝试修正关闭后仍腐坏、仍可作为合成热源的问题，并支持记住开关、联机确认。升级时先移除旧 `CageFix.dll`，只保留新 `ET-Fix.dll`；原配置继续使用。见 [独立说明](src/外部mod/ET-Fix/README.md)。
