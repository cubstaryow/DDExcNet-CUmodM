# DDEN.UnitListMgr（内部附属模块）

源码位于现有仓库 src/DDEN.UnitListMgr，输出 DDEN.UnitListMgr.dll，初始实验版本 0.1.0-alpha。依赖 DDEN.Shared 2.0.0 / API v1，管理器适配 2.0.0；作为独立附属发布，不加入原五组件发布清单。不依赖 MPfix，不修改外部模组。

## 操作与默认值

- 主界面在管理器“物品工具”打开；F7 打开该页，无管理器时显示独立窗口。点击物品查看默认属性，可编辑数量、耐久／电量、弹药、弹夹、电池种类及多种液体，然后在本玩家脚下生成。液体数量决定容器状态。
- 八个快捷槽只保存物品 ID。默认按住 F8，鼠标移向对应槽，松开后在最终鼠标世界位置生成一个物品；中心、Esc、右键、失去焦点取消。热键可以修改，冲突可能自动换键。
- 快捷模式从不读取主面板编辑状态。弹药补到该物品 maxRounds；枪械不装弹夹、枪膛为空；电池与液体沿用游戏／CCL 定义和初始化流程。CCL 的 SpawnWithBattery=false、StartCharge、注射器 DefaultContents 均保留，不能把所有物品都视为“满耐久、空内容物”。
- 搜索使用游戏本地化名称与 ID；物品目录来自 Item.GlobalItems，支持 CCL 注册。列表按可见行绘制，选中时读取模板，图标保持比例。查看目录不在世界创建预览物品，也不激活模板。

## 多人与失败边界

主机执行所有多人生成：sv_cheats 必须开启，客机另需 AllowClientCheatCommands。客机请求使用 CCL sender-aware 接口；主机从桥提供的发送者解析其身体，不接受请求中伪造玩家身份。主客机需安装工具，客机还需兼容的 CCL 联机桥。不同端的物品注册必须一致。

主面板由主机计算本玩家脚下位置；鼠标模式限制距请求玩家 60 米内，以覆盖 MP Item.Start 的邻近注册路径。每批最多 20 个、至少间隔 0.5 秒；请求 ID 去重并缓存结果，超时不自动重发、不在客机补本地副本、不在原工厂失败时再次生成。初始化异常可能留下部分已生成物品，结果返回其数量，不能保证事务回滚或消除其他模组损坏模板的问题。

CCL 工厂只调用一次；在原 Item.Start 前消费 CCL 电池初始化，再施加用户修改，交给原 MP Item.Start 注册。未对 CPU 优化／CCL 模板添加保护或修改其他模组。IPlayerStateEditor 仅预留契约，当前没有角色状态编辑器或生物生成功能。

## 验证

执行 tools/UnitListTests 的离线策略检查和 DDExcNet.slnx Release 构建。未启动游戏；中文搜索、实际默认内容、物理落点、快捷键输入隔离和真实主客机同步仍须游戏内验收。构建默认 DeployOnBuild=false；发布、打包及部署由负责发布的协作者执行。

## 网格筛选与结果提示（2026-11-23）

物品页现为多列紧凑卡片；悬停显示完整名称和 ID。来源多选与用途多选组合：同组取并集、不同组取交集；不选用途表示全部用途。CCL 注册物品包含使用 CCL 的第三方模组，不代表可辨认具体作者。无法确认来源归为其他／未识别。原版来源读取游戏原始注册元数据，分类不生成物品或遍历加载全部模板。CCL 的 Container 定义作为容器依据；继承 LiquidItemInfo 但容量为零的普通 CCL 物品不会因此被归为液体。

顶部物品选项卡可用，生物／单位为禁用预留入口。轮盘卡片整体避开屏幕边缘，保持间距。主面板固定结果条；屏幕提示成功绿 5 秒、失败红 10 秒、等待主机蓝色，轮盘关闭后仍可见。实际属性、权限与生成位置规则保持原样。
