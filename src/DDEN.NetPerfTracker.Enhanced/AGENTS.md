# 性能跟踪器增强模块约束

遵守仓库协作约定与 `src/AGENTS.md`。本模块由用户在2026-11-24明确要求建立，专门承载深层诊断Harmony计时；基础 `DDEN.NetPerfTracker` 继续保持零Harmony补丁。

- 仅对已核对的Together、LES、游戏物体和CPU优化模组中的无参、静态或实例、托管void入口安装纯计时前缀与finalizer（2026-11-24用户要求扩大覆盖范围）。不挂接原生／extern或泛型方法。不复制反编译实现，不改第三方DLL文件。
- 前缀必须为void；finalizer必须为void且异常按值传入。不得跳过原方法，不改参数、返回值、异常、物品、世界状态或网络消息。
- 主开关默认关闭。基础性能采样、Together探针及本模块三个条件同时满足才挂接；暂停、禁用或退出时按自身owner撤下，不卸载其他补丁。
- 固定容量计时槽，只统计主线程，完整渲染帧提交窗口；固定更新可在一帧发生多次。父子项为含子项时间，不相加。
- 只取有限集合的Count，不遍历全世界或物品。方法缺失或签名不匹配时保留未知状态，不能伪造零耗时。
- 基础模块与增强模块仅通过版本化JSON反射桥通信，禁止相互硬引用；Together及其网络库仍不硬引用。
- 导出时可只读查询有限插件信息与Harmony补丁元数据，区分导出时状态与历史状态；不调用被观测的业务方法，不逐帧构建归属表。
- 构建及离线验证不能替代Unity／真实多人验收。运行假方法撤钩检查使用 `tools/PerfEnhancerHookTests/run-netfx.ps1`；不启动游戏。
- 独立可选组件，当前不加入六组件发布包；打包、部署依照用户当次授权与协作者分工。
