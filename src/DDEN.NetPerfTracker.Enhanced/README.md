# 性能跟踪器增强 · 0.1.0-alpha

为性能跟踪器2.2.0提供Together逐函数耗时。它是独立可选组件，默认关闭；基础跟踪器不依赖它，仍然没有Harmony补丁。本模块仅计时，不改变游戏逻辑，也没有优化补丁。

将 `DDEN.NetPerfTracker.Enhanced.dll` 与更新后的性能跟踪器放在插件目录，使用同一份Shared。在性能分析的“告警与联机反馈”页开启“Together探针”和“深层计时”；也可以从管理器的“性能跟踪器增强”页开启。暂停、停用采样或任一诊断开关后，会撤下自有钩子。无管理器时默认F10打开增强页，快捷键冲突时以配置为准。

计时范围为 `chunks` 的3个入口、`fixed` 的2个入口、`opt` 的6个入口，以及含子项的 `OptimizerMain.Tick` 总项。显示完整帧数、平均／峰值每帧耗时、调用次数、平均／峰值每次耗时及异常结束次数；额外读取8个内部集合的Count，用于比较队列／对象数量。

启用与撤下钩子可能造成一次卡顿，启用后先等几秒再比较。函数耗时包含其他补丁及等待，不是纯CPU执行时间；父项包含子项，不能相加。缺少方法、签名不兼容或挂接失败会显示不可用。关闭不清除基础跟踪器已有历史，手动“导出日志”保存 `DEEP_WINDOW` 记录。

编译与检查、指标口径见 [性能说明](../../docs/perf-tracker.md) 与 [开发说明](../../docs/development.md)。真实Unity／多人兼容性和采样开销仍需实测。
