# 性能跟踪器增强 · 0.2.1-alpha

为性能跟踪器提供Together逐函数和逐帧耗时。它是独立可选组件，默认关闭；基础跟踪器不依赖它，仍然没有Harmony补丁。本模块仅计时，不改变游戏逻辑，也没有优化补丁。

将 `DDEN.NetPerfTracker.Enhanced.dll` 与更新后的性能跟踪器放在插件目录，使用同一份Shared。在性能分析的“告警与联机反馈”页开启“Together探针”和“深层计时”；也可以从管理器的“性能跟踪器增强”页开启。暂停、停用采样或任一诊断开关后，会撤下自有钩子和帧循环计时标记；页面只通过管理器打开。

计时范围含Together、LES、物体更新，以及主机检查点、诊断扫描、可见性刷新、区块唤醒和对象距离检查；现共53个固定目标，新增NetObjectRegistry.Update、_ObjectSyncUpdateLoopUniversal(bool)及LayerBuildingStream.HostRegister，便于定位周期同步注册扫描。缺少的入口显示不可用。显示完整帧数、平均／峰值每帧耗时、调用次数、平均／峰值每次耗时及异常结束次数；额外读取8个内部集合的Count，用于比较队列／对象数量。

手动导出新增 `DEEP_FRAMES`：保留最近256个完成帧，以及128帧长帧上下文（触发帧前后各4帧，空间不足时覆盖最旧记录）。包括Unity帧号、主机/客机/停服状态、固定步次数、进程GC次数及同帧脚本/2D物理阶段和方法墙钟时间。记录常驻固定容量内存，逐帧不写盘；暂停后仍可导出已有记录，重新开始或清空会重置。MP开始／停止及换世界也会清空深层记录，每段对照必须先导出再切换状态。

P95/P99由所有非预热、非手动导出帧的固定直方图计算，上界精度0.1ms，达到1000ms溢出档时分位数显示未知；不是从被挑选的长帧计算。前2秒和手动导出帧明确标记，排除在该统计之外。GC次数不是GC耗时；2D固定阶段不是精确求解器CPU耗时，阶段与父子函数时间不能相加。帧LoopMs是本模块帧循环边界之间的墙钟时间，不直接当成GPU时间或FPS。

启用与撤下钩子可能造成一次卡顿，启用后先等几秒再比较。函数耗时包含其他补丁及等待，不是纯CPU执行时间；父项包含子项，不能相加。缺少方法、签名不兼容或挂接失败会显示不可用。关闭不清除基础跟踪器已有历史，手动“导出日志”保存 `DEEP_WINDOW` 记录。

编译与检查、指标口径见 [性能说明](../../docs/perf-tracker.md) 与 [开发说明](../../docs/development.md)。真实Unity／多人兼容性和采样开销仍需实测。
